Triple-Quote Preview

A shortcut for printing several lines with just one print()

📜 So far every new line of output has needed its own print() call. Python has a shortcut: wrap text in triple quotes — """ — and press Enter inside them. Every line you type becomes a new line of output, all from one print(). 
print("""Hello
World
Goodbye""")
💡 Run the example below to confirm your prediction. Then edit it into your own multi-line message (a short poem, an address, a mini fact file — anything with at least 3 lines) — keep it inside one print() using triple quotes.
