Write an algorithm that tells a customer to return their parrot if it is dead.

Scenario

A pet shop has a self-service kiosk. Customers use it to check whether they need to return a parrot to the store. The kiosk asks the customer whether their parrot is dead, and if it is, tells them to return it to the store.

Your algorithm must:

  • Ask the customer whether their parrot is dead
  • If the parrot is dead, output a message telling them to return the parrot to the store

Extra challenge (not marked): if the customer says the parrot is not dead, keep asking until they agree that it is.

Write an algorithm that works out whether a cat is happy, not happy, or angry.

Scenario

Maria has built a smart cat-monitoring app. It asks whether her cat is purring — a purring cat is happy, and a cat that isn't purring is not happy. It then separately checks whether the cat's tail is swishing, which is a sure sign the cat is getting angry.

Your algorithm must:

  • Ask whether the cat is purring
  • Output that the cat is happy if it is purring, or that it is not happy if it is not
  • Ask whether the cat's tail is swishing
  • Output a message warning that the cat is angry if the tail is swishing

Extra challenge (not marked): make the program repeat this check for five different cats.

Write an algorithm that works out how much food to prepare for an afternoon tea.

Scenario

A hotel's afternoon tea order system works out how much food to prepare. Every guest gets 1 sandwich and 3 cakes — but if there are more than 3 guests, the kitchen makes one less cake overall to avoid waste. For example, 4 guests need 4 sandwiches and 11 cakes.

  • Calculate and output the correct number of cakes, applying the one-less-cake rule for groups larger than 3
